# 分类评估指标

## 核心界定

准确率衡量总体正确比例，精确率关注预测为正的样本有多少是真的，召回率关注真实正例找回多少。 本节把“分类评估指标”放在机器学习基础的课程体系中理解，回答它研究什么、解决什么问题以及答题时应先写出的中心判断。关键词包括准确率、精确率、召回率、F1、混淆矩阵。
