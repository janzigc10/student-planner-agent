# 交叉验证

## 核心界定

交叉验证把数据划为若干折，轮流用一折验证并汇总结果。 本节把“交叉验证”放在机器学习基础的课程体系中理解，回答它研究什么、解决什么问题以及答题时应先写出的中心判断。关键词包括K折、轮换、均值、方差、数据泄漏。
