欧洲一体化是指欧洲整体或部分地区在政治、法律、经济、社会、文化等领域的区域一体化历史。现代欧洲一体化主要由欧洲联盟和欧洲委员会推动进行。最初提出欧洲一体化构想的是理察·尼古拉斯·冯·康登霍维-凯勒奇，他在1923年发表了一篇名为《泛欧罗巴》的宣言。


== 历史 ==
在古代，罗马帝国带来了多个欧洲和地中海领土的融合。 后来，由于1950年后的欧洲一体化提供了灵感和历史先例，对罗马帝国以及古典帝国本身的许多后续继承主张进行了重新解释。
到了现代时，如何避免民族国家之间的战争的问题对于最初的理论至关重要。联邦主义和功能主义提出了对民族国家的遏制，而交易主义则试图将民族国家体系稳定的条件理论化


== 欧洲委员会 ==
欧洲委员会于1949年创立于斯特拉斯堡，被认为是欧洲一体化开始具体实现的第一步。


== 欧洲安全与合作组织 ==
欧洲安全与合作组织成立于1973年，的成立目地是确保欧洲安定，成员国横跨大西洋。


== 欧洲联盟 ==
欧洲联盟是欧洲多国共同建立的政治及经济联盟，现拥有27个成员国。
欧盟的主要机构有欧洲理事会（成员国家首脑组成）、欧盟理事会（成员国家部长组成的欧盟的上议院）、欧盟委员会（欧盟的行政机构）、欧洲议会（欧盟的众议院，唯一的直接民选机构）、欧洲法院、欧洲中央银行等。此外，欧洲原子能共同体也在欧洲共同体的管辖范围之内，但在法律上是独立于欧盟的国际组织。
欧元由27个成员国中的20个采纳为流通货币；《申根条约》取消部分成员国之间的边境管制，目前已有22个欧盟成员国和4个非成员国实施，欧盟公民在各国之间也直接享有工作权，甚至一部分的政治参与。在外方面，具备欧洲公民权的可申请使用标记欧盟标注的成员国护照，同时也享有所有成员国的领事保护资格。
目前欧盟的主要议题有欧洲联盟扩大、落实《里斯本条约》、全球暖化问题、非欧元区成员国加入欧元区、欧洲主权债务危机、欧洲移民危机等。


== 区域性一体化 ==


=== 波罗的海国家 ===
苏联解体之后，波罗的海三国爱沙尼亚、拉脱维亚及立陶宛基于防范取代苏联的俄罗斯及加强自身安全，展开了多种合作。1992年，波罗的海三国和其他波罗的海沿岸国家成立了波罗的海国家理事会，其后三国一同加强合作，并一同加入欧盟及北约，彻底脱离俄罗斯的影响。


=== 比荷卢三国 ===
位于欧洲中部及法国及德国之间的比利时、荷兰和卢森堡在一战结束之后就开始合作。1921年，比利时就和卢森堡组成了经济同盟，两国成为单一市场并且货币等值。1948年，比荷卢三国创建了比荷卢三国关税同盟。之后就逐渐成为欧盟的前身。
